# book

A personal EPUB-to-GitHub-Pages book reader, optimised for commute reading (≤ 30 min per session).

## How it works

1. Drop an `.epub` file into `books/`.
2. Run `npm run parse` — it detects the next unparsed chapter, converts it to a beautiful HTML page in `docs/chapters/`, and regenerates the index.
3. Commit & push — GitHub Pages serves `docs/` automatically.
4. Repeat every two days, or whenever you want the next chapter.

Each run parses **exactly one chapter**. If a chapter is too long (> 32 min estimated reading time), the script uses Claude to find a good narrative break and splits it into two parts.

## Setup

### 1. Install dependencies

```bash
npm install
```

### 2. Set your Anthropic API key

The script calls Claude for:
- Generating an engaging Chinese summary at the top of each page
- Finding the best narrative split point for long chapters

Export your key before running:

```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

Or create a `.env` file in the project root:

```
ANTHROPIC_API_KEY=sk-ant-...
```

### 3. Enable GitHub Pages

In your repo settings → Pages → Source: **Deploy from a branch** → branch `main` → folder `/docs`.

## Usage

```bash
# Add a book
cp ~/Downloads/my-novel.epub books/

# Parse the next chapter
npm run parse

# Commit the generated page
git add docs/ state.json
git commit -m "Add chapter: Chapter 1"
git push
```

## Design

- **Theme**: [Flexoki Light](https://stephango.com/flexoki) — warm paper-like background (#FFFCF0), easy on the eyes.
- **Typography**: System serif fonts with good CJK support; comfortable 19 px / 1.85 line-height.
- **Reading progress bar**: Thin teal line at the top of every chapter page.
- **Summary**: A ~100-word Chinese paragraph generated by Claude, shown before the chapter text to entice you to read.

## File layout

```
books/          ← drop .epub files here (gitignored)
docs/           ← GitHub Pages root (committed)
  index.html    ← regenerated book/chapter list
  chapters/     ← individual chapter HTML files
scripts/        ← TypeScript source
  parse.ts      ← main entry point
  epub-parser.ts
  llm.ts
  html-generator.ts
  types.ts
state.json      ← tracks which chapters have been parsed
```
